# Inner Melbourne Volunteer Atlas

A map and register of 40 volunteer groups across inner Melbourne (Naarm) caring for people and Country, with how much time each one asks of a volunteer.

- `index.html`: the atlas. A single self-contained page with no build step and no dependencies.
- `melbourne-volunteer-groups.csv`: the same data with coordinates, for spreadsheets, Airtable, Notion or GIS.

## Publish with GitHub Pages

1. Push these files to a repository.
2. Go to **Settings > Pages**, set the source to the `main` branch, root folder.
3. The atlas will be live at `https://<your-username>.github.io/<repo-name>/`.

## About the data

Compiled October 2026 from each group's own pages and current volunteer listings. Each row links to its source.
Hours per month are a rough guide for one regular volunteer. Rows marked *unconfirmed* don't publish a commitment, so check with the group.
Locations are approximate and the map is schematic.

Corrections and new groups are welcome via issues or pull requests.
